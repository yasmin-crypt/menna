# Menna Allah Mohamed — Portfolio

Single-page portfolio website (HTML/CSS/JS, no build step).

## Run locally
Open `index.html` in any browser.

## Deploy online
Upload `index.html` to any static host (Netlify Drop, GitHub Pages, Vercel, Cloudflare Pages).

## Add contact details
Open `index.html`, find `var CONTACT = { email: "", linkedin: "", whatsapp: "" };` near the end of the file, and fill in your details. The contact buttons appear automatically.
